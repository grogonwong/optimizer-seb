OPTIMIZER SEB V1

Pemeriksaan jaringan dan kesiapan komputer sebelum ujian memakai Safe Exam Browser (SEB).

PENTING: Hasil script ini bukan sertifikasi keamanan atau alat untuk menyadap; alat ini hanya untuk pengecekan jaringan. Lakukan uji buka SEB sebelum sesi ujian dimulai.

MAC OS
1. Buka TERMINAL (gunakan spotlight jika tidak ketemu) 2.  ketikan "bash <(curl -fsSL https://raw.githubusercontent.com/grogonwong/optimizer-seb/main/OPTIMIZER_SEB_V1_macOS.command)"  tanpa tanda kutip
3. isi password mac lalu enter 4.  tunggu hingga selesai

WINDOWS 10/11

1.buka powershell
2. klik kanan run as adminstrator
3. ketik "irm https://raw.githubusercontent.com/grogonwong/optimizer-seb/main/OPTIMIZER_SEB_V1.ps1 | iex" tanpa tanda petik
4. tunggu hingga selesai
